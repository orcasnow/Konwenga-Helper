# Dankoba Helper Local Ver.2.0

Windows用の単体実行ファイル `Dankoba_Helper_Local.exe` の利用ガイドです。試合情報や記事メモを入力して、Markdown形式のマッチプレビューをローカルに作成します。

## 配布ファイル

Releaseから `Dankoba_Helper_Local.exe` をダウンロードして起動してください。利用するPCへのPython、pip、Playwrightのインストールは不要です。PlaywrightとChromiumは実行ファイルに含まれます。

アプリの起動に必要な配布物はexeだけです。このガイドもReleaseに添付すると、利用者が操作や制限を確認しやすくなります。

初回起動時は、同梱ファイルをWindowsの一時フォルダーへ展開するため、起動に時間がかかることがあります。実行時の試合情報・公式リンク・天気の取得にはインターネット接続が必要です。

このアプリはWindows向けです。exeを作成する開発者向けの手順は、プロジェクトの `README_LOCAL.md` を参照してください。

## 基本的な使い方

1. 上部のラジオボタンから大会種別を選びます（J1、J2、J3、天皇杯、ルヴァンカップ）。
2. 「試合情報」タブで自チームと対戦相手を入力します。この2チームと大会種別が必須です。記事番号、布陣、日付、会場などは空欄でも検索を始められます。
3. 「記事本文」タブにリード文、試合の見どころ、戦術メモなどを入力します。空欄の項目はテンプレート内の執筆メモとして残ります。
4. 「大会種別」の右側にある「ローカル取得設定」で、公式リンク、順位表、ハイライト、Playwrightの再取得を切り替えます。
5. 「Markdown を作成」を押します。選択した取得処理が終わると、反映された試合情報と検索結果の確認画面が出ます。続行すると保存先を選べます。

確認画面で「いいえ」を選ぶと、Markdownは作成されません。検索で補った値は入力欄に残るため、修正してからもう一度作成できます。保存先選択をキャンセルした場合も作成を中止します。

## 既定の取得設定

初期状態は次のとおりです。

| 設定 | 初期状態 |
| --- | --- |
| 対戦クラブの公式リンク | 有効 |
| 順位表 | J1/J2/J3では有効、天皇杯/ルヴァンカップでは無効 |
| 相手の前節ハイライト | 有効 |
| Playwrightによる表示ブラウザー再取得 | 有効 |

大会種別を変更すると、順位表のチェック状態もその大会の初期値に切り替わります。切り替え後はチェックを手動で変更できます。

シーズン欄の初期値は8月境界で決まります。8〜12月はその年の8月開始、1〜7月は前年8月開始のシーズンになります。必要に応じて手で変更してください。

## 情報取得の流れ

### 試合日程と試合情報

アプリはPCの現在日付から14日先までを対象に、選択した大会と両クラブを指定してJリーグ公式の日程を検索します。日程一覧から試合ページのURL、日付、チーム名を調べ、条件に合う試合のうち最も近い試合を選びます。日程行に日付がない場合は、試合ページURLに含まれる日付も使います。

ページはまず静的HTMLとして取得します。条件に合う試合を判定できない場合、設定が有効ならPlaywrightの表示ブラウザーでも再取得します。取得した試合ページからラウンド、キックオフ、開催区分、会場、住所、地図URL、中継などを読み取ります。チーム名やページ構造が変わった場合は、自動判定できないことがあります。

自動取得値は、対応する入力欄が空欄の場合だけ反映されます。入力済みの値は自動取得値で上書きしません。日程を取得できなくてもMarkdown作成は続行でき、手入力値を使えます。

### 天気

天気は会場名、住所、キックオフ日がそろっていて、天気欄が空欄の場合に tenki.jp から取得します。時刻が分かる場合は時間別の予報を優先し、対象日が時間別予報の範囲外なら日単位の予報を調べます。予報の掲載期間外、会場を特定できない場合、取得先に接続できない場合は空欄のままになります。

### クラブ公式リンク

有効にすると、両クラブの公式サイトから試合情報、アクセス、スタジアムグルメ、グッズなどの参考リンクを探します。見つかったリンクは確認画面に件数が表示され、Markdownの参考リンクへ追加されます。見つからないカテゴリや取得できなかったサイトは追加されません。

### 順位表

有効な場合、自チームの所属カテゴリの順位表をJリーグ公式から取得します。大会種別をJ1/J2/J3にしたときは既定で有効、天皇杯/ルヴァンカップにしたときは既定で無効です。取得できない場合も、他の入力内容からMarkdownを作成できます。

### 前節ハイライト

有効な場合、実行日から暦上2カ月前までの日程・結果を調べ、相手チームの過去試合ページを日付の新しい順に確認します。候補ページは新しい順で最大4件まで調べ、自動取得できた対象試合ページは読み飛ばします。動画が見つからない場合は次の候補を確認し、見つかれば参考情報としてMarkdownへ追加します。

動画はJリーグ公式の試合ページにあるレビュー欄の埋め込み情報から探します。公式ページに動画がない場合や、動画部分が読み込めない場合は取得できません。

## 出力ファイル

保存先の選択画面でMarkdownファイルの名前と場所を指定します。記事番号が入力されていれば、初期ファイル名に番号と対戦カードが使われます。

画像を選んだ場合は、Markdownと同じ場所に `attachments` フォルダーを作って画像をコピーし、Markdownから相対パスで参照します。同名ファイルがある場合は、上書きせず `-2` などの番号を付けた名前で保存します。画像付きMarkdownを別の場所へ移すときは、Markdownと `attachments` フォルダーを一緒に移動してください。

参考リンクを追加する場合は、「参考リンク・画像・取得設定」タブで1行ずつ `表示名 | URL` の形式で入力します。

## ログとトラブルシューティング

「参考リンク・画像・取得設定」タブの処理ログには、日時、取得先、取得方法、警告が表示されます。取得できなかった項目がある場合は、確認画面の注意件数とログの詳細を見てください。

- **Playwrightの再取得が動かない**: 配布版ではPlaywrightとChromiumを同梱しています。起動に失敗する場合は、実行ファイルを一時フォルダーへ展開できる空き容量と書き込み権限を確認してください。
- **試合やリンクが見つからない**: 入力した大会、チーム名、日付を確認し、空欄の項目は「試合情報」タブで入力してください。
- **403などの拒否が出る**: 接続先のアクセス制限やIP制限によっては、表示ブラウザーでも取得できません。ログに警告を残し、取得できない項目は手入力できます。
- **取得値が古い、または内容が違う**: 自動取得値は確認画面で確認してから作成してください。必要に応じて入力欄を修正できます。
- **天気が空欄**: 会場名・住所・キックオフ日を確認してください。予報の掲載前や取得先の応答がない場合も空欄になります。

アクセス先のrobots.txtが取得を許可していないページは読み込みません。同一サイトへの連続アクセスには間隔を設けています。アクセス制御を回避するものではありません。

## データとプライバシー

Markdownと画像は指定したPC上の保存先に作成されます。GoogleアカウントやGoogle Driveへのアップロードは行いません。取得設定を有効にした場合、検索に必要なページをJリーグ公式、クラブ公式サイト、tenki.jpなどへリクエストします。
